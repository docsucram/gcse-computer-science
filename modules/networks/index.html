⭐ Star Topology in GCSE Exams

In a star network, each workstation has its own dedicated connection to a central switch. Advantage: If one workstation cable breaks, no other device is affected. Disadvantage: If the central switch fails, the entire network goes down (Single Point of Failure).

Exam Tip: AQA often asks why a school would choose a star topology over a bus topology. Key answers: higher bandwidth per machine, no packet collisions, and cable breaks only affect one computer.

Encryption Concepts & Exam Notes

Plaintext vs Ciphertext

Plaintext: The original, readable message before encryption (for example, "Meet at the cafe at 4pm!").

Ciphertext: The encrypted, scrambled data transmitted across the network (for example, 0x53 0x65 0x65...). Without the secret key, it appears as random noise.

Symmetric vs Asymmetric Encryption

Symmetric: Uses one single secret key to both encrypt and decrypt (such as AES). It is fast and computationally lightweight, but introduces the Key Exchange Problem: transmitting the key across an insecure network risks interception.

Asymmetric: Uses a mathematically linked key pair (a Public Key to encrypt and a Private Key to decrypt, or Diffie-Hellman key exchange). This resolves the key-sharing dilemma across public channels.

Why WhatsApp and HTTPS Use Hybrid Encryption

Asymmetric mathematics (such as 2048-bit modular exponentiation) requires intensive CPU processing and is too slow for large files or live video streams.

The Solution: Modern networks use Asymmetric Key Exchange (Diffie-Hellman) for a fraction of a second to establish a shared secret key, and then immediately switch to fast Symmetric Encryption (AES) for all subsequent message traffic.

Common Exam Pitfall: The Public Key

Common Mistake: Suggesting that "the public key must be kept secret so unauthorized users cannot access it."

Key Principle: The Public Key is intentionally public and broadcast openly. It can only be used to encrypt data or mix pigments. Only the corresponding Private Key can decrypt the resulting data.

Networks Revision Guide & AQA Exam Traps

Plain, readable, high-impact GCSE facts directly aligned with the CGP revision textbook.

1. What are the 3 parts of a packet?

AQA questions consistently test this exact trio:

  • Header: Sender IP, Recipient IP, Packet Sequence Number, Total Packets, and Protocol.
  • Payload: The slice of actual user data.
  • Trailer: Checksum (CRC) for error detection.

2. IP Address vs MAC Address

  • MAC Address: Physical address burnt into the NIC by the manufacturer. 48 bits written in hex. Used locally (LAN).
  • IP Address: Logical address assigned by the network. 32-bit (IPv4) or 128-bit (IPv6). Used across the internet (WAN).

3. Domain Name System (DNS)

Computers route numbers, humans remember words. When you type bbc.co.uk, your computer queries a DNS server to look up the corresponding IP address (e.g. 151.101.0.81) before sending the request.

4. Router vs Switch vs WAP

  • Router: Connects different networks (LAN to WAN). Reads IP addresses to choose optimal paths.
  • Switch: Connects devices on the same local network. Reads MAC addresses.
  • WAP: Uses radio waves to connect wireless devices to a wired network.

⚠️ Classic AQA Exam Traps

  • Trap 1: The Internet is the physical worldwide network of cables and routers. The World Wide Web is the collection of web pages accessed via HTTP over the Internet!
  • Trap 2: In packet switching, packets take independent routes and arrive out of order—they do not travel on a dedicated single wire.
