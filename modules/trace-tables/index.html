Structuring Code into Modules

Decomposition, subroutines, and AQA Structure Charts.

🧩

What is a Subroutine?

A named, self-contained block of code that performs a single specific task. Divided into Functions (which return a value) and Procedures (which execute actions).

👑

The "Main Module" (main())

The master conductor / orchestrator of the program. It controls top-level sequence and flow, delegating detailed math, I/O, and validation to specialised subroutines.

🚀

4 Golden Exam Advantages

1. Reusability (eliminates duplicate code).
2. Easier Debugging (isolate bugs to 1 module).
3. Unit Testing (test algorithms alone).
4. Teamwork (split modules between coders).

🎯

Single Responsibility

A good module does one job well. Don't create "god functions" that do 10 things at once, and don't make subroutines for trivial 1-liners like x = x + 1!

            ✓ Functions vs Procedures (Core Exam Definition)
          

          

            AQA examiners frequently ask: "State one difference between a function and a procedure."
          

          

            • Function: Must calculate and return a value back to the calling statement (e.g. price = calculate_ticket_price(age)). Represented by the ↑ ○ Return Arrow on Structure Charts.

            • Procedure: Executes instructions (e.g. printing a receipt or updating a database) but does NOT return a value.
          

        


        
        

          

            🔒 Local vs Global Scope & Parameters
          

          

            Why does modular code keep software free from accidental bugs?
          

          

            • Local Variables: Declared inside a subroutine. Accessible only within that subroutine. Automatically deleted from memory when the subroutine finishes.

            • Global Variables: Declared in the main script. Accessible anywhere. Risky because any function can accidentally modify them, causing unexpected bugs.

            • Parameters: The safe, professional way to pass data into subroutines without relying on global variables.
