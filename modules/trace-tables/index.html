AQA Exam Mark Scheme Criteria:

Structuring Code into Modules

Decomposition, subroutines (functions vs procedures), and AQA Structure Charts.

🧩

What is a Subroutine?

A named, self-contained block of code that performs a single specific task. Divided into Functions (which return a value) and Procedures (which execute actions without returning a value).

👑

The Main Module

The master orchestrator of the program. It controls top-level sequence and flow, delegating detailed calculations, data validation, and input/output to dedicated subroutines.

🚀

4 Key Exam Advantages

1. Reusability: Eliminates duplicated code.
2. Simpler Debugging: Isolate defects to one subroutine.
3. Unit Testing: Test modules independently.
4. Team Collaboration: Divide modules across programmers.

🎯

Single Responsibility

A well-designed module focuses on one job. Avoid monolithic subroutines that try to do everything, and avoid splitting off trivial one-liners like x = x + 1.

            Functions vs Procedures (Core Exam Definition)
          

          

            AQA mark schemes distinguish between functions and procedures based on return values:
          

          

            • Function: Calculates and returns a value back to the calling statement (e.g. price = calc_ticket_price(age)). Represented by the ↑ ○ Return Arrow on Structure Charts.

            • Procedure: Executes actions (e.g. printing a ticket receipt or updating a database record) but does not return a value.
          

        


        
        

          

            Local vs Global Scope & Parameters
          

          

            Why does modular code keep software free from accidental side effects?
          

          

            • Local Variables: Declared inside a subroutine. Accessible only within that subroutine and freed from memory when execution ends.

            • Global Variables: Declared in the main program. Accessible everywhere, but risky because unintended modifications can introduce subtle bugs.

            • Parameters: The controlled mechanism for passing values into subroutines without relying on global variables.
