Negative Numbers: Sign & Magnitude (-127 to +127)
Hardware Dilemma

Computer chips have no physical minus sign (−) switch, so negative numbers need to be stored in binary just like any other number. The obvious first idea was: reserve the Most Significant Bit (MSB) as the 'sign' bit (0 = positive, 1 = negative), while the remaining 7 bits represent the positive magnitude.

While this is a simple and intuitive solution, it introduces two fatal hardware problems:

Flaw 1 Two Zeros (+0 & -0)

00000000 is +0, but 10000000 is -0! Having two zeroes wastes a unique binary pattern and forces processors to do double comparisons for every if (x == 0) check in hardware.

Flaw 2 Normal Addition Fails!

If the computer tries to calculate 7 + (-3), normal binary addition gives the completely wrong answer:

  00000111 (+7)
+ 10000011 (-3 in Sign & Mag)
------------------------
  10001010 (= -10 in Sign & Mag!)

Instead of +4, normal addition outputs -10! The processor cannot use its standard addition circuit for negative numbers.

Negative Numbers: Two's Complement (-128 to +127)
The Genius Solution

The Genius Solution: To solve the problems of Sign & Magnitude, computer scientists made the Most Significant Bit (MSB) worth -128 instead of +128. This solves both flaws: there is only one zero (00000000), and the processor can use its exact same addition circuit for subtraction with zero extra hardware!

To convert a positive number to Two's Complement:
Step 1: Write the positive number in standard binary.
e.g. +3 = 00000011
Step 2: Invert all the bits (0 ↔ 1, One's Complement).
→ 11111100
Step 3: Add 1! (Two's Complement).
11111100 + 1 = 11111101 (= -3)
Addition is Solved: 7 + (-3) Works!
If the computer now calculates 7 + (-3) using Two's Complement:
  00000111 (+7)
+ 11111101 (-3 in Two's Comp)
------------------------
(1)00000100 (= +4!)

The 9th carry bit (1) spills past the 8 bits and is discarded by the CPU. The remaining 8 bits equal exactly +4! Standard addition handles subtraction with zero extra circuits.

Hexadecimal Numbers (Base 16)
Base 16

Long binary strings like 11011010 are difficult to read and error-prone for humans. Computer scientists use Hexadecimal (Base 16) as a compact, human-friendly shorthand. Because 16 = 2⁴, each hexadecimal digit represents exactly 4 binary bits (1 nibble).

Common Notations

0x Prefix: Standard in programming (e.g. 0x2A, 0xFF)
# Hash: Used in web design & colours (e.g. #FF5733)
Subscript 16: Standard in exams (e.g. 2A₁₆)

Converting Hex to Denary

Multiply the high digit by 16, then add the low digit:
3F₁₆ = (3 × 16) + 15 = 48 + 15 = 63

The "10" Trap

• 10₁₀ (Denary): Ten (1 ten + 0 units)
• 10₁₆ (Hexadecimal): Sixteen (1 sixteen + 0 units)
• 10₂ (Binary): Two (1 two + 0 units)
The written digits "10" always equal the base value itself.

Logical Binary Shifts

Multiplication & Division by Powers of 2

In computer architecture, a Logical Shift moves all bits inside a register to the left or right. Vacated positions are always padded with 0. Shifting left multiplies the number by 2 for each position shifted ($2^1 = 2, 2^2 = 4, 2^3 = 8$), while shifting right performs integer division by 2.

Hardware Rule Vacated bit positions are always padded with 0 in logical shifts. When shifting left, if a 1 falls off past bit 7 (128), an overflow error occurs. When shifting right, if a 1 falls off past bit 0 (1), fractional precision is truncated/lost.

Deep Dive & Real World

Deep Dive: Why Do Both kB and KiB Exist? (The Hard Drive Storage Mystery)

The secret behind "missing" gigabytes

Why does a 1,000 GB drive show as 931 GB in your operating system?

1. Hardware Manufacturers sell in Decimal (SI): Hard drive and SSD makers count in standard everyday powers of 10. To them, 1 GB = 1,000,000,000 bytes (109).

2. Operating Systems calculate in Binary (IEC): Because computer memory (RAM) is wired in powers of 2, operating systems address storage using 1,024-byte multipliers: 1 GiB = 1,073,741,824 bytes (230).

The Result: When you plug in a 1,000 GB drive, Windows divides the 1,000,000,000,000 bytes by 1,073,741,824. The drive isn't faulty or secretly robbed of space — it's simply a difference between base-10 and base-2 math!

Number Systems Revision & Exam Traps

Essential definitions, calculation rules, and exam traps for Paper 2 (§3.3.1 & §3.3.2). Master binary place values, two's complement, arithmetic overflow, logical shifts, and data units.

RULE 1: PLACE VALUE & HEX Paper 2 §3.3.1

Binary (Base 2) & Hexadecimal (Base 16)

• Binary Place Values: 128, 64, 32, 16, 8, 4, 2, 1 for an 8-bit byte. Range of an unsigned byte is 0 to 255.
• Hexadecimal: Uses digits 0–9 and letters A–F (A=10, B=11, C=12, D=13, E=14, F=15).
• Why Hex? Much easier for humans to read and remember than long binary strings; exactly 1 hex digit represents 4 bits (1 nibble), and 2 hex digits represent 1 full byte (8 bits).

Exam Tip: To convert binary to hex, split into 4-bit nibbles from the right, convert each nibble to denary, then write the hex symbols.
RULE 2: ADDITION & OVERFLOW Paper 2 §3.3.1

Binary Addition & Overflow Error

• Addition Rules: 0+0=0, 1+0=1, 1+1=0 carry 1, 1+1+1=1 carry 1.
• Overflow Error: Occurs when the sum exceeds the allocated number of bits (e.g. an 8-bit result > 255). The MSB carry has no storage slot and is dropped, causing incorrect results.
• Consequence: In software, overflow can cause silent bugs or security vulnerabilities (buffer wrap-arounds).

Exam Trap: If an exam question asks "What error occurs if 11111111 + 1 is stored in an 8-bit register?", the answer is Overflow Error.
RULE 3: UNITS & STORAGE SIZE Paper 2 §3.3.2

Decimal vs Binary Data Units

• Bit vs Byte: 1 bit = single 0 or 1. 1 byte (B) = 8 bits. 1 nibble = 4 bits.
• Decimal Prefixes (Powers of 10): 1 kB = 1,000 B, 1 MB = 1,000 kB, 1 GB = 1,000 MB, 1 TB = 1,000 GB.
• Binary Prefixes (IEC, Powers of 2): 1 KiB = 1,024 B (210), 1 MiB = 1,024 KiB (220), 1 GiB = 1,024 MiB (230).
• AQA Exam Note: AQA accepts decimal 1,000 multipliers for kB/MB unless specified otherwise in the question.

Watch Out: Small 'b' means bits (e.g. 100 Mbps network speed). Capital 'B' means bytes (e.g. 500 MB storage). Divide bits by 8 to get bytes.
RULE 4: NEGATIVE NUMBERS Paper 2 §3.3.1

Two's Complement & Sign Bits

• Two's Complement: The most significant bit (MSB) represents -128 instead of +128. Range of an 8-bit signed byte is -128 to +127.
• Negating a Value: To find the negative counterpart of any binary number, invert all bits (0→1, 1→0) and add 1.
• Sign & Magnitude: An alternative method where the MSB is simply 0 for positive and 1 for negative, but suffers from two zeros (+0 and -0).

Exam Trap: Two's complement range is asymmetrical (-128 to +127) because zero uses one of the positive bit combinations (00000000).
RULE 5: BINARY SHIFTS Paper 2 §3.3.1

Logical Shifts (Multiplication & Division)

• Logical Left Shift: Shifts bits left by n positions, inserting 0s at the right. Multiplies the value by 2n.
• Left Shift Risk: If 1 bits are shifted out of the MSB, overflow occurs and precision is lost.
• Logical Right Shift: Shifts bits right by n positions, inserting 0s at the left. Performs integer division by 2n.
• Right Shift Truncation: Any 1s shifted off the right boundary are dropped (integer truncation / loss of precision).

Exam Note: Shifting 00000101 (5) right by 1 bit gives 00000010 (2) because the fractional 0.5 is truncated.
