Binary Search O(log₂ N)

Binary Search is a fast algorithm for finding an item in a SORTED list. Instead of checking every item one by one from the start, it jumps straight to the middle item. If the target is smaller, it throws away the entire right half of the list; if larger, it throws away the entire left half. Then it repeats until it finds the target.

  • Data must be sorted beforehand. It does not work on random lists.
  • Efficiency: Extremely fast on big datasets. Doubling the list size only adds 1 extra check!
  • Worst case: Searching 1,000 items takes at most 10 checks (2¹⁰ ≈ 1,000).
Exam Rule: If an exam question asks you to search an unsorted list using Binary Search, the answer is: you can't — you must sort it first or use Linear Search!
Linear Search O(N)

Linear Search is a straightforward algorithm that starts at the very beginning of a list and checks every single item one by one in order until it either finds the target or runs out of items. It doesn't need the list to be in any special order, but it gets painfully slow on large datasets.

  • Works on any list — even completely unsorted, messy data.
  • Efficiency: Inefficient on big datasets. Every extra item means one more possible check.
  • Worst case: Searching 1,000 items might take all 1,000 checks.
Efficiency Comparison: On 1,000,000 items, Linear search might need 1,000,000 checks. Binary search finishes in just 20 checks.
